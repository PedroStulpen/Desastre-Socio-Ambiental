# Sistema de Gestão de Doações e Distribuição Humanitária

## 📋 Sobre o Projeto

Sistema web desenvolvido para **gerenciar o recebimento, controle e distribuição de doações destinadas às vítimas de desastres ambientais e situações de emergência**, como enchentes, deslizamentos e outras calamidades públicas.

O objetivo da plataforma é facilitar a organização das ações humanitárias, conectando pontos de arrecadação, centros de distribuição e locais que necessitam de assistência, proporcionando maior eficiência, transparência e agilidade na entrega de recursos essenciais à população afetada.

## 🎯 Objetivo

Centralizar o gerenciamento de doações, permitindo identificar as necessidades de cada local de atendimento e direcionar os recursos disponíveis conforme a demanda registrada, evitando desperdícios e contribuindo para uma distribuição mais justa e organizada.

## ⚙️ Principais Funcionalidades

- **Gestão de Usuários:** Cadastro e gerenciamento dos usuários responsáveis pelas operações do sistema.
- **Cadastro de Locais:** Registro dos pontos de recebimento de doações, centros de distribuição e locais de atendimento às vítimas.
- **Cadastro de Itens:** Gerenciamento de alimentos, roupas, produtos de higiene, água potável e outros materiais essenciais.
- **Controle de Doações:** Registro e acompanhamento dos itens recebidos.
- **Solicitação de Recursos:** Permite que os locais de atendimento informem os produtos e as quantidades necessárias.
- **Gestão de Distribuição:** Organização e registro da distribuição dos itens conforme as necessidades identificadas.
- **Acompanhamento de Demandas:** Visualização das solicitações realizadas pelos locais cadastrados, auxiliando na priorização e no direcionamento dos recursos.

## 🛠️ Tecnologias Utilizadas

O sistema foi desenvolvido utilizando as seguintes tecnologias:

- **Frontend:** Angular e TypeScript.
- **Backend:** ASP.NET Core (API REST em C#).
- **Banco de Dados:** MySQL.
- **Arquitetura:** Aplicação web com comunicação entre frontend e backend por meio de API REST.

## ❤️ Impacto Social

A plataforma foi idealizada para apoiar ações de solidariedade e assistência humanitária, oferecendo uma ferramenta tecnológica capaz de melhorar a logística de distribuição de donativos durante situações de crise.

Ao permitir que cada local registre suas necessidades, o sistema contribui para que **as doações cheguem aos locais certos, de acordo com a demanda real**, auxiliando voluntários, organizações e equipes envolvidas nas operações de assistência às vítimas.

**Tecnologia a serviço da solidariedade e da reconstrução de comunidades.**
